# Khaled Mhamdi — Engineering Portfolio

Public website: https://khaledmh1991.github.io

Five pages cover process engineering, utilities, ENERWISE energy optimization and carbon management, and project management. English and French content, original engineering figures, and a full-size figure viewer are included.

## Hosting and editing

This repository contains the deployable static website. GitHub Pages publishes the `main` branch from the repository root. Edit HTML, CSS, JavaScript, or images directly and commit to update the site. No paid service or build dependency is required.

The original project is built using `PORTFOLIO_SITE_ORIGIN=https://khaledmh1991.github.io node build.mjs`; this repository contains the output of that build.

Engineering case-study figures are supplied by Khaled Mhamdi. The utilities balance uses the replacement image with redacted labels. The project-management stock photo is illustrative; attribution is in `assets/image-credits.md`.
